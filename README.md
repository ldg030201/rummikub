# 🀄 온라인 루미큐브 (Rummikub)

React + Vite 프론트엔드와 Node.js(`ws`) 실시간 서버로 만든 **실시간 멀티플레이 루미큐브**.
로컬 서버 하나만 켜서 친구들에게 주소를 공유하면 같은 방에 들어와 바로 플레이할 수 있어.

- 실시간 동기화 (WebSocket): 내가 타일을 옮기면 다른 사람 화면에도 실시간으로 보임
- **아무나 "시작"** 버튼을 누르면 게임 시작
- 표준 룰 (첫 등록 30점, 세트/런, 조커, 판 위 자유 재배열)
- **2~6인** 지원 (5인 이상은 자동으로 2세트 = 212타일 사용)
- 새로고침해도 같은 이름으로 자리 복귀 (재접속)

---

## 1. 준비물

- **Node.js 18 이상** (개발/테스트는 Node 24에서 확인)
- IntelliJ IDEA(또는 WebStorm) — 서버를 여기서 켤 거야

## 2. 설치

프로젝트 루트에서 한 번만:

```bash
npm run install:all
```

(또는 `server`, `client` 폴더에서 각각 `npm install`)

---

## 3. 실행 방법

두 가지 모드가 있어. **친구들과 실제로 플레이할 땐 "공유 모드"** 를 쓰면 돼.

### A. 공유 모드 (실제 플레이 · 링크 하나로 공유) ⭐

클라이언트를 빌드해서 Node 서버가 프론트+실시간을 **한 포트에서 전부** 서빙해.

```bash
npm run share
```

이러면 클라이언트를 빌드하고 서버를 `http://localhost:8123` 에 띄워. 이 주소 하나만 공유하면 돼.

> IntelliJ에서 켜는 방법: 오른쪽 위 실행 구성 → `server/src/index.js` 를 Node.js 로 실행하거나,
> 터미널 탭에서 `npm run share` 실행. (프론트를 고친 뒤엔 `npm run build` 를 다시 해야 반영됨)

### B. 개발 모드 (코드 고치면서 개발할 때)

터미널 2개로 나눠서:

```bash
# 터미널 1 — 실시간 서버 (8123)
npm run dev:server

# 터미널 2 — Vite 개발 서버 (5173, HMR)
npm run dev:client
```

접속: `http://localhost:5173`
개발 모드에선 프론트(5173)가 백엔드(8123)로 웹소켓을 자동 연결해.

---

## 4. 친구들에게 공유하기

### 같은 WiFi(LAN)일 때 — 제일 간단

1. **공유 모드**(`npm run share`)로 서버를 켠다.
2. 내 컴퓨터의 로컬 IP를 확인한다:
   ```bash
   ipconfig getifaddr en0
   ```
   예: `172.168.0.134`
3. 친구들에게 이 주소를 공유:
   ```
   http://172.168.0.134:8123
   ```
   (IP는 네트워크마다 다르니 매번 확인해)
4. 같은 방 코드를 입력하면 함께 플레이!

> 접속이 안 되면 macOS **방화벽**에서 Node 의 들어오는 연결을 허용해야 할 수 있어.
> (시스템 설정 → 네트워크 → 방화벽)

### 인터넷 어디서든 — ngrok 터널

같은 WiFi가 아니어도 되게 하려면 [ngrok](https://ngrok.com) 을 쓴다.

1. ngrok 설치 (`brew install ngrok` 또는 공식 사이트에서 다운로드) 후 계정 토큰 등록.
2. **공유 모드**로 서버를 8123에 띄운다.
3. 새 터미널에서:
   ```bash
   ngrok http 8123
   ```
4. ngrok이 준 `https://xxxx.ngrok-free.app` 주소를 친구에게 공유하면 끝.
   (HTTPS라서 웹소켓도 `wss://` 로 자동 연결돼 — 별도 설정 불필요)

## 5. 게임 방법 (룰 요약)

- 시작하면 각자 타일 **14장**을 받아. 목표는 **손패를 가장 먼저 다 내려놓는 것**.
- 낼 수 있는 조합은 2가지:
  - **세트(그룹)**: 같은 숫자 + 서로 다른 색, 3~4개 (예: 🔴7 🔵7 ⚫7)
  - **런**: 같은 색 + 연속된 숫자, 3개 이상 (예: 🔴4 🔴5 🔴6). 13 다음 1로 안 이어짐.
- **첫 등록(브레이크인)**: 처음 내려놓을 땐 내 손패만으로 **합 30점 이상**을 만들어야 해.
  (조커는 대신하는 타일의 숫자로 계산)
- 첫 등록을 한 뒤부터는 **테이블 위 조합을 자유롭게 재배열**해서 내 타일을 끼워 넣을 수 있어.
  단, 턴을 마칠 때 테이블의 모든 조합이 유효해야 함(각 3장 이상).
- **조커(★)**: 아무 타일이나 대체.
- 낼 게 없으면 **"한 장 뽑기"** — 풀에서 한 장 가져오고 턴 종료.
- 조작 방법: 손패/테이블의 타일을 **드래그**해서 조합에 끼우거나 `+ 새 조합` 으로 새 조합을 만들어.
  다 됐으면 **제출**, 되돌리려면 **되돌리기**.

## 7. 자주 겪는 문제

| 증상 | 해결 |
|------|------|
| `EADDRINUSE: address already in use :::8123` | 8123 포트를 이미 다른 게 쓰는 중. 다른 포트로: `PORT=8091 npm start` (공유 모드는 `PORT=8091 npm run share`) |
| 친구가 LAN 주소로 접속 안 됨 | 같은 WiFi인지 확인 + macOS 방화벽에서 Node 허용 |
| "클라이언트가 아직 빌드되지 않았어" 페이지 | `npm run build` 를 먼저 실행 (공유 모드는 자동으로 빌드함) |
| 개발 모드에서 서버 포트를 바꿈 | `client/.env` 에 `VITE_WS_URL=ws://localhost:<포트>/ws` 추가 |

## 8. 구조

```
rummikub/
├─ server/                 # Node.js + ws 실시간 서버
│  └─ src/
│     ├─ index.js          # HTTP(정적 서빙) + WebSocket
│     ├─ game.js           # 방/게임 상태, 턴 진행
│     ├─ rules.js          # 룰 검증 (세트/런/조커/첫 등록/커밋)
│     ├─ tiles.js          # 타일 생성/셔플
│     └─ *.test.js         # 테스트
├─ client/                 # React + Vite 프론트
│  └─ src/
│     ├─ App.jsx           # 화면 라우팅
│     ├─ net.js            # WebSocket 훅 (재접속 포함)
│     ├─ rules.js          # 실시간 UI 피드백용 룰 미러
│     └─ components/       # JoinForm / WaitingRoom / Game / Tile / Toast
└─ package.json            # 루트 실행 스크립트
```

### 동작 개요

- 서버가 **권위 상태(authoritative)**를 가짐. 클라이언트는 조작을 제안하고, 서버가 룰을 검증한 뒤 모두에게 브로드캐스트.
- 내 턴엔 로컬에서 자유롭게 타일을 옮기고(=draft), 옮길 때마다 다른 사람에게 **실시간 관전용으로 전송**돼. **제출**하면 서버가 최종 검증.
- 각자에게 내 손패만 전체 공개되고, 남의 손패는 **장수만** 보여.
